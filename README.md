<!-- DESCRIÇÃO -->
<p align="center">
  <b>End-to-end Data Science pipeline</b> que extrai dados de livros via Web Scraping<br>
  e aplica Machine Learning para prever preços baseado em avaliações.
</p>

---

## 🚀 Project Overview

<p align="center">
  Este projeto combina <b>Web Scraping</b> e <b>Machine Learning</b> em um pipeline completo<br>
  — desde a extração automatizada de dados até a previsão inteligente de preços.
</p>

## 🛠 Tech Stack

<p align="center">
  🔹 <b>Python</b> — Core development & data pipeline<br>
  🔹 <b>BeautifulSoup + Requests</b> — Web scraping & HTML parsing<br>
  🔹 <b>Pandas</b> — Data manipulation & analysis<br>
  🔹 <b>Scikit-Learn</b> — Machine Learning models (Random Forest & Linear Regression)<br>
  🔹 <b>Matplotlib</b> — Data visualization<br>
  🔹 <b>Jupyter Notebook</b> — Interactive development
</p>

## 🎯 Key Features

<p align="center">
  ✔️ <b>Web Scraping Automation</b> — Extrai 1000 livros do site books.toscrape.com<br>
  ✔️ <b>Data Preprocessing</b> — Limpa e estrutura dados de preços e avaliações<br>
  ✔️ <b>Machine Learning Models</b> — Random Forest & Regressão Linear<br>
  ✔️ <b>Model Evaluation</b> — Métricas R² para comparar performance<br>
  ✔️ <b>Price Prediction</b> — Preve preços baseado em avaliações (1-5 estrelas)<br>
  ✔️ <b>Data Export</b> — Salva datasets em CSV para análise futura
</p>

## 📊 Workflow

<p align="center">
  <b>Web Scraping</b> → <b>Data Cleaning</b> → <b>Feature Engineering</b> → <b>Model Training</b> → <b>Price Prediction</b> → <b>CSV Export</b>
</p>

## 💡 Business Value

<p align="center">
  <b>Automated Data Collection</b> elimina entrada manual de dados<br>
  <b>Predictive Analytics</b> permite estimar precos de novos produtos<br>
  <b>Scalable Pipeline</b> pode ser aplicado a outros sites de e-commerce
</p>
